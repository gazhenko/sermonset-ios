# SermonSet

Native Swift / SwiftUI sermon companion. All features remain free.

## First delivery slice

Create a dedicated iOS app with Library, Discover, and Collection navigation,
a prominent Record action, and honest empty states. Private use requires no
account. Reliable private recording and revisit come before community publishing.

The initial repository contains project instructions only, not an implemented app.
Project Desk owns the task board, acceptance criteria, and recorded human decisions:
https://project-desk-sermonset.gazhenko-jemmy.chatgpt.site/?project=sermonset

## Pilot

The owner selected iPhone 17 Pro, iOS 26.6.2, and English. Verify the actual
device and installed SDK before claiming compatibility. Simulator results are
not physical-device evidence. This Mac currently has Xcode 26.6 and XcodeGen.

## Product rules

- A sermon is the useful object; cards point into it.
- Trading never removes a sermon from library history or transfers private notes.
- Preserve original audio. No silent cloud fallback from local-only processing.
- Save capture state before recording; use durable segments and recovery manifests.
- Private capture works without AI, account, location, or internet.
- Summaries require versioned transcript evidence and playable audio ranges.
- Public publishing, rights policy, trading, and moderation are later slices.
- No claims of guaranteed permanent hosting, verified sample content, or tested
  hardware without evidence.
